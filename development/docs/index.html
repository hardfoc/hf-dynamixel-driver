HF-Dynamixel documentation

This site documents the portable hf-dynamixel-driver: a C++17 wrapper around ROBOTIS Dynamixel SDK 4.1.0. HF owns the transport contract, result model, and X-series descriptors. The SDK owns Protocol 2.0 encode/decode.

The first bench servo is XC430-W150 (model 1070). A later larger X-series servo can use the same examples via the catalog (XM430/XH430) or BindXSeriesFallback() after a successful ping.
