◆ ReadTelemetry()

DriverResult< Telemetry > dynamixel::Device::ReadTelemetry ( )
noexcept

Present PWM, load/current, velocity, position, input voltage and temperature in one Read of the contiguous block 124..146, then Hardware Error Status (70). Falls back to one read per register when the block does not fit max_packet_bytes or the servo refuses the range.
